# PropertyChain Security Incident Response and Monitoring (PCSIRM)

PCSIRM is a Flask-based security incident monitoring and response management system developed as a university project. It provides a centralized environment for recording security events, detecting suspicious activity, investigating incidents, managing evidence, tracking response recommendations, and generating reports.

The system is designed to support security monitoring and incident management for a blockchain-enabled property rental application concept.

## Project Objectives

- Record and manage security events.
- Identify suspicious activity using configurable detection rules.
- Generate and manage security alerts.
- Support structured incident investigation and tracking.
- Register digital evidence and verify its integrity.
- Run controlled security simulations.
- Record response recommendations and maintain audit history.
- Generate filtered reports and CSV exports.

## Main Features

### 1. Dashboard
Provides an overview of security events, incidents, alerts, monitoring sources, and system activity.

### 2. Security Event Management
Records security events with severity levels and classifications:

- `REAL` — events recorded during normal application operation.
- `SIMULATED` — events generated by controlled simulations.
- `TEST` — events generated during testing.

### 3. Detection Rules and Alerts
Uses configurable rules to identify repeated or suspicious activity. Matching events can generate alerts that can be reviewed and tracked.

### 4. Incident Management
Supports incident creation, assignment, investigation, status tracking, and timeline records.

### 5. Evidence Management
Supports evidence registration and file uploads. Evidence files are stored outside the public web directory and assigned SHA-256 hashes for integrity verification. Custody records help track evidence handling.

### 6. Controlled Security Simulations
Provides built-in scenarios that generate local simulated security events. These events can pass through the detection system.

Simulations do not contact PropertyChain, Firebase, or Ethereum, and do not execute containment actions.

### 7. Monitoring Sources
Provides a registry for monitoring sources, including their types, monitoring modes, connection status, and check history.

Firebase and Ethereum sources remain planned and disconnected in the current configuration.

### 8. Response Recommendations
Allows authorized users to record, review, approve, and track response recommendations. PCSIRM records these activities but does not execute remediation or containment against PropertyChain.

### 9. Reports
Provides filtered reports for events, incidents, alerts, monitoring sources, simulations, evidence, and audit records. Matching records can be exported as CSV.

### 10. User Settings and Access Control
Supports two user roles:

- **Administrator:** manages users, monitoring settings, detection rules, incident assignments and statuses, and administrative operations.
- **Security Analyst:** reviews events and incidents, registers evidence, and performs permitted investigation and recommendation activities.

The application also uses password hashing, session security, CSRF protection, and role-based authorization.

## Installation and Setup

### Requirements

- Python 3.12 or a compatible supported Python version.
- pip.
- Git (optional, for cloning the repository).

### 1. Clone the repository

```powershell
git clone https://github.com/desire1515/propertychain-security-incident-monitor.git
cd propertychain-security-incident-monitor
```

Alternatively, open the downloaded project directory in PowerShell.

### 2. Create a virtual environment

```powershell
python -m venv .venv
```

Activate it:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

### 4. Configure the application

Set a secret key for the application:

```powershell
$env:PCSIRM_SECRET_KEY = [guid]::NewGuid().ToString("N")
```

For a local HTTP demonstration on the same computer, temporarily disable the secure-cookie requirement:

```powershell
$env:PCSIRM_SESSION_COOKIE_SECURE = "false"
```

This override is only for isolated localhost development. Use secure cookies when serving the application over HTTPS.

Alternatively, configure these values in a local `.env` file. Never commit that file or publish actual secret keys.

### 5. Initialize the database and administrator

Start the application:

```powershell
python app.py
```

Open the application in your browser:

```text
http://127.0.0.1:5000
```

For a new local database only, visit the application once to initialize its schema. Stop the server using `Ctrl+C`, then create an administrator:

```powershell
python create_admin.py
```

Enter the administrator username and password when prompted. Start the application again:

```powershell
python app.py
```

**Important:** If you already have a database and administrator account, do not initialize a replacement database, reset the database, or create another administrator unnecessarily. Preserve existing records.

## Running the Application

Activate the virtual environment, configure the required environment variables, and run:

```powershell
python app.py
```

Then visit:

```text
http://127.0.0.1:5000
```

Sign in using a locally configured PCSIRM account.

## Security and Implementation Limitations

PCSIRM is a security monitoring and incident management prototype. The following limitations should be understood:

- No verified live Firebase integration is currently connected.
- No verified Ethereum or blockchain monitoring adapter is currently connected.
- Controlled simulations generate local records and do not affect PropertyChain.
- Response recommendations are recorded and tracked; automatic containment is not implemented.
- SHA-256 integrity verification can detect changes to stored evidence bytes, but it is not malware scanning or an external digital signature.
- Production deployment and live monitoring integrations require additional configuration, implementation, and security testing.

These limitations are intentional and should be considered when evaluating the current implementation.

## Project Purpose

PCSIRM demonstrates how security events can be collected, classified, analyzed, and managed through a structured incident response workflow. It brings together event monitoring, detection rules, incident investigation, evidence integrity, controlled simulations, response tracking, and reporting in one application.

The project provides a foundation for future integration with verified external monitoring services and real-world security infrastructure.
